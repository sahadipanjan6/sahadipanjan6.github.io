# Dipanjan Saha — GitHub Pages Portfolio

A responsive single-page academic/research portfolio built with plain HTML, CSS and JavaScript.

## Deploy on GitHub Pages

1. Create a GitHub repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Commit and push.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Your site will be available at `https://YOUR_GITHUB_USERNAME.github.io/`.

## Recommended personalization before publishing

- Add your professional headshot if you want one in the hero section.
- Add your Google Scholar, ORCID, GitHub and institutional profile URLs.
- Replace the selected-publications section with your definitive publication list.
- Add a downloadable CV PDF.
- If you own a domain, connect it through GitHub Pages custom-domain settings.

## Files

- `index.html` — all site content and structure
- `styles.css` — premium dark visual system and responsive layout
- `script.js` — navigation, reveal animations and cursor glow

No framework or build tool is required.
